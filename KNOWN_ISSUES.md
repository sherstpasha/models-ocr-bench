# Известные проблемы и ограничения

Здесь фиксируются проблемы конкретных моделей, ограничения окружения и проверенные обходные пути. Метрики и основные таблицы остаются в `README.md`.

## Методологические ограничения

- **Скорость.** Batch size и режим инференса различаются из-за ограничений моделей и backend. FPS и latency относятся к конкретной конфигурации; сравнивать их следует осторожно.
- **Кропы для OCR.** Для `russian_old_orthography`, `handwritten_essay` и `school_notebooks_ru` кропы слов и строк создаются нашими скриптами из страниц и разметки. Способ вырезки влияет на качество распознавания.
- **Подготовка детекции.** Часть разметки преобразуется в общий формат; bbox некоторых моделей переводятся в полигоны. Это влияет на detection-метрики.
- **Предобработка.** Для многих моделей resize, padding, normalization, decoding и postprocessing реализованы в этом репозитории и могут отличаться от оригинального pipeline авторов.
- **Возможные утечки.** Полный состав обучающих данных часто неизвестен, поэтому исключить пересечение с benchmark нельзя. Подтверждённые пересечения отмечаются звёздочкой; отсутствие звёздочки не гарантирует отсутствия утечки.

## Проблемы отдельных моделей

- `trocr_russian_18th_century_printed` нативно падает на Windows даже при небольших batch size, поэтому запускается с batch size 1 и checkpoint каждые 100 примеров.
- `trocr_church_slavonic_handwritten` нативно падает на длинных CUDA-прогонах, поэтому использует batch size 1, высоту 128, `generation_max_length=128` и checkpoint.
- `party_european_languages` потребовала исправления совместимости с Python 3.10 и завершила полный бенчмарк только после снижения batch size до 8 и размера синтетической страницы до 32.
- `yolov8m_historical_line_segmenter` перенесена из детекции слов в детекцию строк, а её bbox преобразуются в полигоны из-за отсутствия instance masks.
